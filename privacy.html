Tomo日記 分析ツール / 制定日: 2026年10月31日

このツールについて

YouTube チャンネル「Tomo 日記」の運営者本人が、自分のチャンネルの分析データを読むためだけに使う個人用のツールです。ほかの方は利用しません。

読み取るデータ

YouTube Analytics API と YouTube Data API を読み取り専用で使い、運営者本人のチャンネルの統計(再生回数・視聴時間・登録者数・流入経路など)と動画のタイトルを取得します。動画の投稿・編集・削除や、コメントの書き込みはしません。

保存と利用

取得したデータは運営者本人のパソコンにだけ保存し、動画づくりの振り返りに使います。第三者への提供・販売・広告への利用はしません。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」(https://myaccount.google.com/connections)から、いつでも取り消せます。

お問い合わせ

YouTube チャンネル「Tomo 日記」(@tomo_diary)の概要欄からご連絡ください。
